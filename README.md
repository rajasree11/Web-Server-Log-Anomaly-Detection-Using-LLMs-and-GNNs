# Web Server Log Anomaly Detection Using LLMs and GNNs

This repository contains the implementation of the paper:

"Comparative Analysis of Large Language Models and Graph Neural Networks for Web Server Log Anomaly Detection"

## Frameworks

### LLM Framework
- Mistral-7B-Instruct
- PEFT / LoRA Fine-Tuning
- Heuristic Label Generation

### GNN Framework
- IP Behavioral Profiling
- Graph Construction
- Graph Convolutional Network (GCN)
- GraphSAGE Validation

## Datasets
1. Custom Apache Web Logs
2. CSIC 2010 Benchmark Dataset
